# 0.1.3 自适应封面瀑布流

馆藏、JAV、关注和资料索引使用自适应多列瀑布流。横封、竖封及不同长度的标题按各列实际高度排列，不按一行中最高的卡片预留空间。列数随可用宽度调整；加载和重试入口跨全部列显示。

媒体卡片先使用服务端取景框或媒体尺寸估计比例，图片加载后采用实际图像比例；刮削封面继续使用正封取景。使用等比完整显示，图片不拉伸，也不为了统一卡片高度额外裁切。空的作品副标题不占行。

复用项目已有 Compose Foundation 中的 [LazyVerticalStaggeredGrid](https://developer.android.com/develop/ui/compose/lists#lazy-staggered-grid)，没有新增布局依赖。保留接近底部自动分页、失败重试、刷新、点击详情与返回操作。

进入视频详情再返回时，列表保留滚动位置、已经加载的分页与图片比例。只有刷新、搜索或切换栏目时重新建立列表状态；已离开的旧列表状态会释放。

合成测试混合横竖封面，检查较短一列继续放置下一张卡片、列内间距、点击详情返回，并复核 435 条连续分页。证据见 `verification/0.1.3/`。此版本不改变服务器或真实馆藏。
