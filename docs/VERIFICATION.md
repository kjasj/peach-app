- 外部来源与 115/PikPak 下载的提交、取消、后处理；真实关注视频、凭据有效/失效、限流与恢复，需要各自的可用测试账号和来源数据。
- 资料采集、图片选择与裁剪、整理预览/执行/回滚、重复项、垃圾清理、同步与修复，尚无每项全流程通过证据。
- 多版本正向分组、时间轴 sprite、字幕在线搜索、网络断开恢复和长时间资源释放，尚未逐项完成自动验收。现有测试不等同于这些项目通过。
- API 26 的编译兼容已经设置，Android 8 运行环境尚未安装；需要另行验证 API 26 的运行行为。当前模拟器为 API 33，不能替代 Android 8 实测。
- HDR、硬件解码、耳机切换、真实手机旋转与持续播放必须在手机测试。
