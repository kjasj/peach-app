# 0.1.2 封面、业务展示与返回导航

JAV 使用服务器刮削封面，读取 `has_cover`、`cover_key/code`、`cover_version` 和 `poster_box`。封面地址与网页一致；竖版卡片按服务端取景框显示正封，双页封套缺少框时按网页正封比例取右侧。缺少刮削封面时才使用视频预览图。详情页使用相同规则。

关注提供动态、创作者、来源与分组、采集计划入口。无动态时显示空状态；来源用名称、平台和关注状态展示。任务中心按正在进行、未执行、最近完成展示任务名称、中文状态和处理进度。普通资料不回显内部锁标识、进程、结果版本和取景算法字段；已登记的业务字段和状态使用中文名称，作品名称及平台专有名称保持原文。

标签、厂牌、实体资料和其他子页有独立返回栈。系统返回键和顶栏返回箭头都回到上一层，恢复父页筛选和已加载条目；切换首页等主栏目会清空子页历史。作品详情和播放器继续优先处理自身返回行为。

播放器区分播放计划失败、媒体 HTTP 错误、网络中断和解码错误，显示中文原因与诊断编号，提供显式重试和关闭。启用 Media3 已提供的解码器初始化失败后备机制，不新增转码服务，也不承诺所有格式可播。该机制见 [Android 官方说明](https://developer.android.com/reference/kotlin/androidx/media3/exoplayer/DefaultRenderersFactory)。

真实服务只读排查遇到 `/api/stream-plan` 返回 `404 {"error":"unavailable"}`；服务端代码在按作品记录无法读取具体文件时返回此结果。直接读取 NAS 文件成功不能证明同一作品记录在 Peach 中可读取。该情况发生在获取媒体前，客户端无法修复服务端的文件记录、挂载或访问范围；本次没有修改后端、真实文件或真实馆藏记录。

合成测试夹具见 `tools/catalog_fixture.py`，可通过 `--media` 和 `--cover` 指定合成 MP4、双页封套 PNG。只监听回环端口，除登录外拒绝业务写入。测试通过记录、截图及 APK 校验值保存在 `verification/0.1.2/`。完整迁移剩余范围见 [VERIFICATION.md](VERIFICATION.md)。
