# 0.1.1 馆藏与导航修复

馆藏接口在返回 `total` 时，`has_more` 可以为 `null`。旧客户端只判断 `has_more == true`，因此停在第一页。现改为优先使用明确的布尔值，否则根据总数和本页实际条数判断下一页。滚动接近底部自动加载，保留手动加载和失败重试入口。

追加页面不再修改已有数组；失败保留已加载内容和下一页位置。刷新、搜索和重新进入页面从第一页开始，避免将末页偏移量保存为页面条件。

导航依据网页 `sidebar.ts` 提供首页、关注、JAV、艺人、标签、厂牌、已标记、管理，另保留播放列表和沉浸模式。JAV 馆藏使用 `jav=1`，艺人/标签/厂牌索引分别使用复数 `kind`，进入作品时使用对应的单数筛选字段。

真实服务只读检查确认 435 个馆藏记录可完整读取：前七页各 60 条，末页 15 条，无重复；没有执行业务写入。回归测试使用合成内容，覆盖自动分页、下一页失败后重试、刷新回第一页及艺人/标签/JAV 导航。

该版本修复上述问题；完整系统迁移的剩余验收范围见 [VERIFICATION.md](VERIFICATION.md)。
